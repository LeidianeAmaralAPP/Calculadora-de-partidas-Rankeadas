# Calculadora-de-partidas-Rankeadas

🎮 Sobre o projeto

Neste projeto, desenvolvi um Classificador de Patentes inspirado no modo CS Ranqueado do jogo Free Fire, utilizando a linguagem JavaScript.
O objetivo foi criar um programa capaz de armazenar nomes de jogadores, suas respectivas quantidades de vitórias e derrotas, calcular o saldo de partidas e classificá-los automaticamente conforme seu desempenho.

📚 Objetivo de aprendizagem

Este projeto foi desenvolvido como parte do desafio prático da DIO, com o propósito de fortalecer os conhecimentos em lógica de programação e desenvolver habilidades utilizando JavaScript.

A temática do Free Fire foi escolhida para tornar o aprendizado mais dinâmico e divertido.
